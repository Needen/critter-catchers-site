# Critter Catchers — Player README (Real & Hybrid)


## About The Mod
Critter Catchers is an unofficial, free fan-made modification of Pokémon Red.
It keeps the familiar adventure and core battle system, while changing the
creature artwork and some of the game's text and presentation.

This ONE README applies to BOTH available editions. You only need to download
and install the edition you want to play.


## Choose Your Edition

### Real Edition
  Creature sprites are based on real-world animals, plants, fungi, and other
  organisms, with a natural-history-inspired appearance.


### Hybrid Edition
  Creature sprites use alternate, more stylized designs inspired by those
  organisms.

Both editions are built around the same original game. The edition choice is
primarily about the creature artwork, not a different storyline or combat
rules. Install one edition at a time; do not layer the Real patch on top of
the Hybrid patch (or vice versa).


## What Has Changed
- Redesigned creature sprites, including front and back battle artwork.
- Updated AnimaDex entries with scientific names and wildlife information.
- Renamed towns, locations, and the villain organization (now PEETAH).
- AI-assisted revisions to the move-name list to better fit real-world
  creatures and their behaviors.
- Blind Battles: the game does not announce move names for either side during
  combat. Watch animations and the remaining battle feedback to follow what
  happened, including misses and status effects.


## What Has Not Changed
This is not a brand-new game, new region, or new story. The original adventure
and underlying battle mechanics remain the basis of the experience. Move-name
revisions are intended as text/presentation changes, not changes to damage,
accuracy, PP, move effects, or overall battle balance. Some moves retain
fantastical or simplified behavior because the original mechanics remain.


## Before You Install
You need:
- A Critter Catchers PATCH for the edition you choose (Real OR Hybrid).
- Your own lawful copy of the original Pokémon Red game in the exact region,
  revision, and file format required by the release's patch instructions.
- A patching utility that supports the extension of your downloaded patch
  (for example, BPS, IPS, or xdelta, as applicable).
- A compatible way to play the resulting modified game image.

The exact patch filename, required base-ROM revision, and checksum must come
from the release/download page. They are NOT verified in this README. If those
requirements are not supplied with the patch, ask the publisher before
patching; do not guess or use a random ROM download.


## Installation — Both Editions
1. Download the patch labeled REAL or HYBRID. Pick ONE edition.
2. Back up your original game image and any existing battery-save (.sav)
   files before making changes.
3. Start with a clean, unmodified copy of the exact required original game.
4. Open a patching tool that supports the downloaded patch format. Select
   the clean original game as the SOURCE and your chosen Critter Catchers
   patch as the PATCH.
5. Save the patched result as a NEW file, leaving the original untouched.
6. Open that resulting game file in your compatible emulator or flashcart
   environment, following that software/device's normal instructions.

If patching fails, confirm the correct original-game revision, checksum, and
patch format. A patch for one edition should NOT be applied on top of an
already modified game or a game modified with the other edition's patch.


## Saves And Cartridges
Keep backups of all .sav files. Do not assume saves can be moved safely
between editions or across updates without verification. If using a physical
flash cartridge, confirm its memory and save support are compatible with the
release build and follow the device manufacturer's flashing instructions.
Compatibility varies; no particular emulator or cartridge is guaranteed here.


## Playtest Status And Feedback
Community playtesting is ongoing. The game has not been represented as having
passed every optional event, hardware configuration, or full fresh regression
run. If you find an issue, please report it on the download/project page with:
  - Edition: REAL or HYBRID
  - Patch version and filename (from your download)
  - Emulator or cartridge and, if possible, its version/model
  - Where the problem occurred
  - What happened versus what you expected
  - Steps to reproduce the issue

Do not upload or attach the original commercial ROM when reporting bugs.


## AI Use And Accuracy Disclosure
Generative AI assisted with the creature artwork and with research and
suggestions for updated move names. Human selection and revision were used
in preparing the mod. The biological names, facts, and behavior analogies
are provided as game-related information, not as a guarantee of scientific
accuracy; please flag any mistakes you notice.
